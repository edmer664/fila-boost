# Security Policy

## Supported Versions

The following versions of Fila-boost currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| 0.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability in Fila-boost, please help us keep the community safe by reporting it **privately**. Please do **not** disclose security vulnerabilities via public GitHub issues, discussions, or social media.

### How to Report

You can report vulnerabilities through either of the following private channels:

1. **GitHub Private Vulnerability Reporting (Recommended)**:
   - Submit a report privately via [GitHub Security Advisories](https://github.com/edmer664/fila-boost/security/advisories/new).
2. **Email**:
   - Send an email to [edmerpizarra@gmail.com](mailto:edmerpizarra@gmail.com) with the subject line `[SECURITY] Vulnerability in Fila-boost`.

### What to Include in Your Report

To help us triage and resolve the issue quickly, please include:
- A detailed description of the vulnerability.
- Step-by-step instructions or a minimal proof-of-concept (PoC) demonstrating how to reproduce the issue.
- The affected component(s) or version(s).
- Any potential impact, attack vector, or suggested fixes (if known).

### Response Process

- **Acknowledgment**: We aim to acknowledge receipt of your vulnerability report within 48 hours.
- **Investigation & Patch**: We will investigate the issue, determine its impact, and prepare a fix.
- **Coordinated Disclosure**: Once a fix is verified and released, we will publish a security advisory and credit the reporter (unless you prefer to remain anonymous).
